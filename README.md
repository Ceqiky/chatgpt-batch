# ChatGPT Batch Prompter

Расширение Chrome, которое отправляет промпты в ChatGPT по очереди, ждёт окончания генерации и скачивает картинки.

**Версия 1.4.3** · [Что нового](CHANGELOG.md) · [Скачать ZIP](https://github.com/Ceqiky/chatgpt-batch/archive/refs/heads/main.zip)

## Возможности

- Очередь промптов: вставка в поле, из `.txt` или `.csv` (колонка `prompt`).
- Ожидание окончания генерации и полной загрузки картинки.
- Скачивание с подтверждением и повторами в `Загрузки/ChatGPT_Images/<дата_имя-csv>/`, имена из колонки `имя_результата`; доработанные — в подпапке `edited/`.
- Отказы ChatGPT по правилам контента и сбои не останавливают очередь: такие промпты откладываются и повторяются кнопкой «Повторить пропущенные».
- Прикрепление файлов: общий файл (например, Word-сценарий), референсы из папки или прямо из таблицы Word-ТЗ.
- Файлы из библиотеки ChatGPT без повторной загрузки — см. ниже.
- Лимиты ChatGPT: очередь сама ждёт и продолжает. Уведомления Chrome о завершении и ошибках.
- Доработка: универсальный промпт (чёрный фон, без текста) после каждой генерации или для папки готовых картинок.
- Работа в фоновой вкладке, пауза и продолжение, повторы при неудаче, подробный журнал и отчёт для отладки.

## Установка

1. Скачайте [ZIP](https://github.com/Ceqiky/chatgpt-batch/archive/refs/heads/main.zip) и распакуйте его, либо `git clone https://github.com/Ceqiky/chatgpt-batch.git`.
2. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку.
4. Откройте chatgpt.com. Панель появится справа внизу или по клику на иконку расширения.

**Обновление:** замените папку новой версией (или `git pull`) и нажмите ↻ у расширения. Версия видна в шапке панели.

Работает в Chrome и браузерах на Chromium (Edge, Arc, Brave) на Windows и macOS.

## CSV

| Колонка | Зачем |
|---|---|
| `prompt` | текст промпта (обязательно) |
| `имя_результата` | имя скачанного файла |
| `реф_файл` | картинка-референс из выбранной папки |
| `строка_в_Word` | строка таблицы Word-ТЗ, например «Слайд 1» |

## Файлы из библиотеки ChatGPT

Файл, уже загруженный в ChatGPT, выбирается через `@имя` — так же, как руками, без повторной загрузки.

- **Один файл ко всем промптам:** впишите его имя в поле «Файл из библиотеки ChatGPT» (например, `IMG_4811`). Пустое поле — файл не используется.
- **Свой файл для промпта:** начните промпт с `@имя`, например `@IMG_4811 /wideshot`. Можно несколько: `@IMG_4811 @logo /combo`. Свой файл заменяет общий.

Кнопка «Проверить» выбирает файл в поле ChatGPT, ничего не отправляя.

## Тестовая страница

`preview.html` имитирует ChatGPT (меню `@`, генерацию, вложения, лимит) для проверки правок без настоящего чата. Параметры адреса: `?plainmenu`, `?slowonly`, `?slowgen`, `?limit`.

## Файлы

- `manifest.json` — описание расширения (Manifest V3).
- `content.js` — панель и вся логика работы со страницей ChatGPT. Селекторы ChatGPT собраны в объекте `SEL` в начале файла.
- `background.js` — скачивание, уведомления, иконка расширения, «будильник» для фоновой вкладки.
- `preview.html` — тестовая страница.
- `example_variants.csv` — пример CSV.

## Важно

Расширение автоматически отправляет сообщения в интерфейс ChatGPT. Держите паузы между промптами, чтобы не упираться в лимиты; автоматизация интерфейса может противоречить правилам OpenAI.
